# About HDLBits

HDLBits is an online platform focused on teaching Verilog HDL through practical coding exercises and real digital design problems.

It offers structured problem sets covering:

- Basic Verilog Syntax  
- Modules & Vectors  
- Combinational Logic  
- Sequential Logic  
- Counters & Shift Registers  
- FSM Design  
- Arithmetic Circuits  
- Verification Concepts  
- Advanced RTL Design Problems  

HDLBits is widely used by students and engineers preparing for:

- FPGA Development  
- RTL Design Roles  
- Digital VLSI Engineering  
- ASIC Design Learning  
- Hardware Verification

# Topics Covered

## Basics
Introduction to Verilog syntax, modules, ports, operators, wires, and simple digital logic circuits.

## Gates & Combinational Logic
Implementation of logic gates, multiplexers, encoders, decoders, arithmetic logic, and combinational circuit design.

## Arithmetic Circuits
Half adders, full adders, ripple carry adders, comparators, and arithmetic operations in Verilog.

## Sequential Logic
Flip-flops, latches, counters, shift registers, clocked circuits, and sequential digital systems.

## Finite State Machines (FSM)
Moore and Mealy FSM implementations, state transition logic, and control circuit design.

## Testbenches
Verification and simulation of Verilog designs using testbenches.

## Advanced Problems
Parameterized modules, complex RTL implementations, and advanced digital design concepts.

# Running Simulations

## Using Icarus Verilog

Compile the Verilog files:

```bash
iverilog -o output testbench.v solution.v
```

Run the simulation:

```bash
vvp output
```

View waveforms using GTKWave:

```bash
gtkwave dump.vcd
```
